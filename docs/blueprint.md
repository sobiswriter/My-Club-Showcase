# **App Name**: DevClub GH Showcase

## Core Features:

- Project Showcase: Mimic GitHub's repository list to showcase member projects.
- Member Directory: Display member profiles using a GitHub "People" or "Contributors" style.
- About Page: Style the "About Us" page as a beautifully formatted README.md file, enhancing readability and familiarity.
- Events Hub: Manage and display club events with a UI inspired by GitHub Issues, including labels, dates, and locations.
- Knowledge Hub: Present blog articles like GitHub documentation or Gists, emphasizing a clean, readable layout.
- Interactive "Join Us" Page: Design the recruitment page to resemble GitHub's "New Issue" form, complete with Markdown support for applications.
- Wall of Fame: Implement a leaderboard styled after the "Contributors" tab, showing member contributions, along with achievement badges on profiles.

## Style Guidelines:

- The color scheme will have a theme switcher allowing for Light, Dark and Dimmed modes, just as on GitHub. The default mode is Light.
- In Light Mode, the background color will be a very light grey (#f6f8fa), the containers a pure white (#ffffff), borders light grey (#d0d7de), and text near-black (#1f2328).
- In Dark Mode, the background will be a dark blue/grey (#0d1117), the containers slightly lighter dark (#161b22), borders dark grey (#30363d), and text off-white (#e6edf3).
- Use action colors as follows: primary action blue (#2f81f7), success/"Go" button green (#2da44e), danger red (#d73a49), "Merged"/Done state purple (#8957e5).
- Font stack will mirror GitHub's: -apple-system, BlinkMacSystemFont, "Segoe UI", Helvetica, Arial, sans-serif, "Apple Color Emoji", "Segoe UI Emoji".
- Use SFMono-Regular, Consolas, "Liberation Mono", Menlo, Courier, monospace for code snippets.
- The Octicons library will be used exclusively for navigation, buttons, info lines, and stats.
- Each project is shown as a box with a 1px border; mimic GitHub spacing and font sizes throughout.
